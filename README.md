# MarkusCraft

A personalized voxel sandbox game that runs in the browser: explore a procedurally
generated world, break blocks and build with them – with unlimited blocks in a Creative
world, or with what you gathered yourself in a Gathering world. Everything in it – code, terrain and
textures – is original work generated by the code in this repository.

## Play

Once GitHub Pages is enabled (see below), the game is served at
`https://markushornbach.github.io/MarkusCraft/`. It needs a browser with WebGL2.

Supported devices:

- **Computers** with keyboard and mouse: current Chrome, Edge or Firefox. Safari on a Mac
  should work but is not tested.
- **Android phones and tablets** with Chrome, held in landscape, using the on-screen touch
  controls. iPhone and iPad are not supported; the game may or may not work there.

### Keyboard and mouse

| Input            | Action                                                         |
| ---------------- | -------------------------------------------------------------- |
| Mouse            | Look around                                                    |
| W A S D          | Move                                                           |
| Space            | Jump / swim up / fly up (Creative)                             |
| Shift            | Sprint                                                         |
| F                | Toggle fly mode (Creative only)                                |
| C                | Fly down (Creative only)                                       |
| Left click       | Break the targeted block; in a Gathering world hold the button |
| Right click      | Place the selected block                                       |
| 1–9, mouse wheel | Select a slot of the bar                                       |
| E                | Open and close the inventory                                   |
| F3               | Toggle the debug overlay                                       |
| Esc              | Close the inventory, or release the mouse and pause            |

### Touch controls (phone and tablet)

Create or choose a world in the world menu and tap its play button. The game then shows
its touch controls and, where the browser allows it, switches to fullscreen; it does not
capture a mouse. Hold the device in landscape, otherwise the game asks you to rotate
it.

```
+--------------------------------------------+
| [menu]                       [bag] [fly]   |
|                                            |
|                     +                      |
|                                     [up]   |
|   ( o )                      [break]       |
|   stick                  [place]  [down]   |
|        [1][2][3][4][5][6][7][8][9]         |
+--------------------------------------------+
```

| Control          | Action                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| Left thumb       | A stick appears where you touch the lower left part of the screen. Push it to move; push it all the way to sprint |
| Drag, right half | Look around                                                                                                       |
| Break (pick)     | Break the block at the crosshair; hold to keep breaking (in a Gathering world: hold until the block gives way)    |
| Place (block +)  | Place the selected block at the crosshair; hold to keep placing                                                   |
| Up (▲)           | Jump; swim up; rise when flying                                                                                   |
| Down (▼)         | Descend when flying (Creative only)                                                                               |
| Fly (wings)      | Toggle fly mode; the button is green while flying (Creative only)                                                 |
| Bag              | Open the inventory; it closes with its "Close" button                                                             |
| Block bar        | Tap a slot to select it                                                                                           |
| Menu (☰)        | Pause and open the menu                                                                                           |

In a Gathering world the fly and down buttons are missing and the bag button sits in the
corner instead.

The menu in touch mode has a **Fullscreen** button (after "Exit fullscreen" the game no
longer enters fullscreen by itself during that visit), a **Debug overlay** switch and a
**Touch sensitivity** setting for the look speed. On a fresh device the render distance
starts at 5 chunks to keep the frame rate up; it can be raised in the menu.

The mode follows the way the play button is pressed: a tap starts touch mode, a mouse click
starts mouse mode. Adding `?touch=1` to the address forces touch mode. The touch controls
react to fingers only, so on a computer this needs a touch screen or the device emulation
of the browser's developer tools.

### Worlds and saving

The game starts with the **world menu**. A world has a name, a seed (the number the
terrain is generated from) and a game mode:

- **New world**: choose a name; leave the seed empty for a random world, or type a number
  or any text to get the same terrain again. Choose the mode, **Gathering** (preselected)
  or **Creative**; it belongs to the world and cannot be changed later. "Create and play"
  starts it.
- **Play**: the list shows your worlds, the one played last on top. Select one and press
  "Click to play" (or "Tap to play").
- **Delete** removes the selected world for ever, after asking once.
- In a world, the pause menu (Esc, or the menu button on a touch screen) has **Save and
  back to worlds**. It also has a button that copies a link with the world's seed; opening
  such a link (`?seed=<number>`) offers to create a new world with that terrain. A link
  carries the terrain only, not what was built.

Worlds are **saved automatically**: a few seconds after every change, when the game is
paused, when the page is hidden or closed, and when you go back to the world menu. The
pause menu shows "Saved" when everything is written.

**Where the data lives, and how it can be lost.** Worlds are stored in this browser, on
this device only (in the browser's IndexedDB storage for the game's address). There is no
account, no cloud copy and no export. A world is gone if

- the browser's site data for the game is cleared ("clear browsing data", "delete cookies
  and site data"), or the browser or its profile is removed;
- the game is opened in a private / incognito window, which forgets everything when it is
  closed (some browsers cannot save there at all; the menu then says so);
- the device runs very low on storage and the browser clears data of sites by itself. The
  game asks the browser to keep its data ("persistent storage"), but the browser decides.

Another browser, another device or another address (for example a local development
server instead of the published site) each have their own, separate worlds. A world cannot
be open in two tabs at once; the second tab says so.

### Game modes

|           | Creative                                | Gathering                                         |
| --------- | --------------------------------------- | ------------------------------------------------- |
| Blocks    | Unlimited; placing uses nothing up      | Only what you broke yourself; placing uses it up  |
| Breaking  | At once                                 | Takes time: hold until the block gives way        |
| Flying    | Yes                                     | No                                                |
| Inventory | A palette of all blocks to fill the bar | 27 slots plus the bar, up to 99 items per slot    |
| Dangers   | None                                    | None (peaceful: no health, no hunger, no enemies) |

**Breaking in a Gathering world.** Hold the left mouse button (or the break button) on a
block. Cracks spread over it and a bar under the crosshair fills; when it is full the
block is gone and lands in your inventory, with a short note such as "+1 Dirt". Letting
go, looking at another block or changing the selected slot starts over. By hand, leaves
take a quarter of a second, glass 0.4 s, sand and dirt 0.6 s, grass 0.7 s, clay 0.8 s,
planks 1.5 s, a log 2 s, stone and bricks 3 s, coal ore 3.5 s and iron ore 4.5 s. Coal ore
yields a lump of coal instead of the block. If nothing more fits, the game says
"Inventory full" and the block stays. Bedrock and water cannot be broken.

**The inventory** (E, or the bag button). The bar at the bottom of the screen holds nine
slots; the selected one is what you place. The inventory screen shows the bar and

- in a Gathering world 27 more slots. Click or tap a stack, then another slot, to move it
  there: onto an empty slot it moves, onto the same kind the stacks merge (up to 99), onto
  another kind the two swap. The **bin** throws the picked stack away for ever.
- in a Creative world a palette of every block. Click or tap a block to put it into the
  selected slot of the bar, or pick a bar slot first and then the block.

The game does not pause while the inventory is open. The inventory is saved with the
world.

**The terrain.** Hills above a certain height are bare rock; coal and iron ore lie in the
stone and clay in lake beds. Nothing can be made from them yet (planned: crafting with a
workbench and a furnace).

### One-time setup for deployment

The owner must set **Settings → Pages → Source** to **GitHub Actions** once. After that,
every push to `main` builds the game and deploys it (`.github/workflows/deploy.yml`).

## Develop

Requires Node 22 (see `.nvmrc`).

```bash
npm ci
```

```bash
npm run dev
```

`npm run build` creates the static site in `dist/`; `npm run preview` serves it.

## Test

| Command                   | What it does                                                 |
| ------------------------- | ------------------------------------------------------------ |
| `npm run check`           | Type check, lint and unit tests (fast gate for every commit) |
| `npm run test:coverage`   | Unit tests with coverage thresholds                          |
| `npm run test:e2e`        | Build, then Playwright browser tests with software WebGL     |
| `npm run test:e2e:update` | Same, regenerating the reference screenshots                 |
| `npm run check:all`       | Everything above except coverage                             |

Browser tests need Chromium for Playwright: `npx playwright install chromium` on a local
machine (cloud sessions ship a matching browser; see `CLAUDE.md`).

Project conventions live in `CLAUDE.md`, phase plans and reports in `docs/`.
